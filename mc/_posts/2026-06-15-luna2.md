## Apply to College-2

最近不仅在构思文书，同时也在看很多别人之前写过的文书，别人的过去、别人的回忆。

当然也开始写自己的文书。开了很多个文档，标题是一串日期，分不清哪个是哪个。有的写了三行就停了，有的写了一整页，然后又删了大半。

对自己写出来的总是不满意。

写了这个开头，觉得还可以，继续写下去。写到第二段，忽然觉得不对。盯着屏幕看了一会儿。然后把第二段全删了。只剩下第一段孤零零地浮在白纸上。

就这么写了很多彼此剥离开来的小文段，只有开头，没有中间，更没有结尾。甚至连开头都称不上，有些文档里只有一句话，有些文档里甚至只是半句话，有些文档里甚至只有一个单词。

每次都是对接下来的内容不满意，然后保存了文档，又新建一个新的文档，继续构思。

现在桌面上打开了大大小小的有了10篇起稿，思考许久后，决定一个一个的关了文档，尽管有些句子自己是很喜欢的。

word 文档的默认弹窗弹出来：Do you want to save the changes made to the document “1-2”? Do you want to save the changes made to the document “1-3”? Do you want to save the changes made to the document “1-4”?.. ..Your changes will be lost if you don’t save them.犹豫了一两秒之后，选择了”NOT SAVE”。任凭其永久消失，内心里什么都没想。

之后，我又重新新建了一个文档、两个文档、三个文档….

一片空白。

删掉那些自己自认为很喜欢的句子，也是因为自己觉得这是删掉名为语言的骗术，写文书的同时也是在欺骗自己、欺骗未来。

自己完全想象不出来自己写完文书的样子。

到那个时候我是否就成为了自己所欺骗自己成为的样子了？

文字不畅，不谙人心。
